# आपका विश्वास • सदैव आपके साथ (Aapka Vishwas Web & Mobile Portal)

यह प्रोजेक्ट **'आपका विश्वास • सदैव आपके साथ'** का आधिकारिक डिजिटल मंच है, जिसे **पूर्ण वेब ऐप्लिकेशन (Full Web Application)** के रूप में तैयार किया गया है।

## 🌐 वेब ऐप्लिकेशन की मुख्य विशेषताएं (Web Features)
1. **🎨 डिजिटल पोस्टर व बैनर स्टूडियो (Poster Maker)**:
   - 4:5 HD पॉलिटिकल बैनर मेकर
   - कार्यकर्ता की फोटो, नाम, पद व मोबाइल नंबर स्वतः सेट
   - विभिन्न थीम्स (भगवा, रॉयल नेवी ब्लू, तिरंगा सेवा, फेस्टिव गोल्ड)
   - एक-क्लिक में **HD PNG डाउनलोड** एवं **सीधा व्हाट्सएप शेयर**
2. **🔥 केंद्रीय चुनाव वॉर रूम (War Room)**:
   - लाइव वीडियो व ऑडियो संवाद ब्रिज (Live Meeting Bridge)
   - 284 बूथों का लाइव ट्रैकिंग स्टेटस व चुनावी समीक्षा
   - संगठनात्मक कार्यक्रम व RSVP (अवश्य आऊँगा / शायद / अनुपस्थित)
   - अति आवश्यक कार्यालय परिपत्र व सीधी समस्या निवारण प्रणाली
3. **📢 मुख्य जनसंपर्क व सोशल फीड (Feed & News)**:
   - दैनिक राजनीतिक अपडेट, जनसुनवाई एवं आधिकारिक प्रेस वक्तव्य
   - सोशल मीडिया शेयरिंग (#AapkaVishwas) व लाइक सिस्टम
4. **🎬 वीडियो व रील्स गैलरी (Videos & Reels)**:
   - आधिकारिक राजनीतिक जैकेट (Branded Jacket Overlays) के साथ वीडियो प्लेयर
5. **🛡️ योद्धा मंच व डिजिटल पहचान पत्र (Volunteer I-Card)**:
   - QR कोड आधारित आधिकारिक डिजिटल सदस्यता कार्ड (I-Card)
   - दैनिक फील्ड टास्क चेकलिस्ट एवं विधानसभा लीडरबोर्ड
6. **👤 प्रोफाइल व सदस्यता प्रबंधन (Profile)**:
   - पद, मंडल, विधानसभा क्षेत्र, और सोशल मीडिया लिंक्स का संपादन

## 🚀 AI Studio Web Application में GitHub से कैसे शुरू करें (How to Import to AI Studio Web)

1. **GitHub पर पुश करें (Push to GitHub)**:
   - अपने इस कोड को अपने GitHub रिपॉजिटरी में कमिट व पुश करें।
2. **Google AI Studio खोलें**:
   - AI Studio में **"New App"** या **"Import from GitHub"** विकल्प चुनें।
   - अपने GitHub रिपॉजिटरी का URL डालें।
   - टारगेट रनटाइम में **Web (Node.js / React)** चुनें।
3. **AI Studio का ऑटोमेशन**:
   - AI Studio प्रोजेक्ट में `package.json`, `vite.config.ts`, और `src/` को तुरंत पहचान लेगा।
   - यह स्वतः `npm install` चलाएगा और `npm run dev` को पोर्ट `3000` पर होस्ट `0.0.0.0` के साथ प्रारंभ कर देगा।
   - आपका वेब ऐप्लिकेशन सीधे ब्राउज़र में लाइव दिखने लगेगा!
